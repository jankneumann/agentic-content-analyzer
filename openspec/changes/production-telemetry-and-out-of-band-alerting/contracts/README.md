# RI-09 planning contracts

- `workflow-alert-envelope.schema.json` is the closed external webhook body.
- `staging-evidence.schema.json` is the only checked-in external-delivery proof.
- `db/schema.sql` records persistence invariants; Alembic and bootstrap SQL are
  authoritative during implementation.

The external contract is intentionally narrower than operation results and
generic notification payloads. It must not be generated by recursively
redacting either of those open structures.
