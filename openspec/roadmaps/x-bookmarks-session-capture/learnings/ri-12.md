# Learning: ri-12

## Decisions
- **Fetch then persist**: XBookmarksIngestionService walks every page before writing; credential failure on any page gives zero rows and the session code with command_key x_bookmarks
- **Backfill cursor**: a partial walk stores x_bookmarks.backfill_cursor in settings_overrides; each run walks the head with stop_when, then resumes the backfill with remaining budget; exhausted clears it; full ignores and resets it
- **Cross-source dedup**: an existing Grok search row with the same xpost id is flagged bookmarked instead of duplicated; xsearch force_reprocess no longer inserts next to a bookmark row
- **Shared renderer**: xsearch thread markdown and metadata builders are shared; Grok search output unchanged; optional Quoted Post section

## Deviations
- Plan: call on_content_ingested reference hook → Actual: removed after host review (reason: no other adapter uses it and it enqueued a legacy job via asyncio.run in the worker)
- Plan: no resume after a capped run → Actual: durable backfill cursor added after host review (reason: older bookmarks were stranded after the first capped run)
- Plan: implementer run → Actual: container restart cut off the rework report; host verified all four fixes and ran the full validation (reason: environment restart)

## Recommendations
- ri-13: hook in at XBookmarksIngestionService._expand_links with the written posts only; record content_references explicitly and submit url operations through OperationService
- ri-17: document aca sources enable x_bookmarks:account, the backfill cursor, --full, and scheduling aca ingest x-bookmarks separately for a quiet hour
- Nothing exercised against live x.com
