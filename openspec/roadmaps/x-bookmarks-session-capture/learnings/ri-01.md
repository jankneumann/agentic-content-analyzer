# Learning: ri-01

## Decisions
- **Loopback binds behind tailscale serve**: API (systemd aca-api.service, ACA_API_HOST=127.0.0.1) and OpenBao (deploy/gx10/docker-compose.gx10.yml, ${ACA_BAO_BIND_ADDR:-127.0.0.1}:8200) listen on loopback; tailscale serve terminates Let's Encrypt TLS on the MagicDNS name
- **Configurable proxy trust**: docker-entrypoint.sh reads ACA_API_HOST and ACA_FORWARDED_ALLOW_IPS with the old defaults, so Railway is unchanged and gx-10 trusts only 127.0.0.1 for X-Forwarded-For (the login rate limiter keys on it)
- **Workstation BAO_ADDR**: https://gx-10.<tailnet>.ts.net:8200 via tailscale serve; no BAO_CACERT needed

## Deviations
- Plan: compose override for gx-10 → Actual: standalone deploy/gx10 compose file with a raft OpenBao server (reason: compose merges ports lists, so an override cannot remove the dev 0.0.0.0:8200 publish; dev overlay is also in-memory -dev mode)

## Recommendations
- ri-15: use optional_host_permissions plus chrome.permissions.request for the tailnet origin, then drop the interim chrome-extension:// ALLOWED_ORIGINS note
- Nothing verified on a live tailnet; operator must run the Verify section of docs/TAILNET.md (task 4.4 open)
- Follow-up outside this roadmap: a production/gx-10 profile and loopback binds for the data stores in the root docker-compose.yml
