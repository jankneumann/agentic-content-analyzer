# Learning: ri-14

- **Problem bodies for this prefix**: error_handler problem-path prefix added so a 422 never echoes the submitted cookie as input

- Plan: declare in canonical OpenAPI → Actual: not declared (reason: v1.yaml holds only workflow routes; admin routes follow the /api/v1/sources precedent)

- Operator: one real curl PUT on gx-10, then confirm the audit row with admin_key_fp
