# Learning: ri-07

## Decisions
- **Single source of truth for the profiles root**: src/config/browser_profiles.py owns DEFAULT_BROWSER_PROFILES_DIR, browser_profiles_dir(), excluded_roots() and EXCLUDED_PATH_PATTERNS; settings.browser_profiles_dir (BROWSER_PROFILES_DIR) configures it
- **Two independent exclusion checks**: component pattern .aca/browser-profiles catches the default layout for any user; resolved configured root catches unusual locations and symlinks
- **Only two copy paths exist**: artifacts tar and FileSyncer; pg_dump, graph dumps, bao snapshot and sync export/import carry no local files

## Deviations
- Plan: one exclusion rule → Actual: pattern plus resolved-root rule (reason: aca-backup runs as a different user so ~ resolves elsewhere)
- Plan: harden the systemd unit with ProtectHome → Actual: unit unchanged (reason: would silently drop artifact paths under /home)

## Recommendations
- ri-08: create per-site profiles as browser_profiles_dir()/site with mode 0700 and import from src.config.browser_profiles
- tar exclusion flags are GNU-only; gx-10 has GNU tar 1.35
