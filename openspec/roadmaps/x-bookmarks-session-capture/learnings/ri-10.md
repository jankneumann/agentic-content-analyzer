# Learning: ri-10

## Decisions
- **Fixed single-account identity**: XBookmarksSource always keys as x_bookmarks:account (X_BOOKMARKS_LOCATOR); aca sources enable x_bookmarks:account
- **Ships disabled**: sources.d/x_bookmarks.yaml has enabled: false so a fresh install's scheduled pipeline stays green
- **Descriptor and provider readiness**: scheduled bulk planner maps max_entries to max_items, passes expand_links, ignores the period; readiness via the credential provider only: credentials_missing unless both X cookies, session_expired if either rejected
- **Fail-closed stub orchestrator**: ingest_x_bookmarks returns status error with source_unavailable and persists nothing until ri-12

## Deviations
- Plan: worker dispatch map entry → Actual: unchanged (reason: worker.py ingest_content map is legacy and its only producer is filtered out; canonical path goes through IngestionService)
- Plan: quiet-hour schedule → Actual: deferred to ri-12 (reason: sources.d has no per-source schedule and the source ships disabled)

- ri-12: emit a ConfiguredSourceResult for the snapshot's public key so IngestionService does not count the source as omitted
