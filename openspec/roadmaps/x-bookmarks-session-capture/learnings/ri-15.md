# Learning: ri-15

## Decisions
- **Popup sync buttons over a pure module**: extension/session_sync.js holds cookie reading, permission origin, https check, PUT and status mapping with no DOM or chrome globals; popup has one button and status line per site
- **Runtime tailnet permission**: optional_host_permissions https://*.ts.net/*; options Save requests the API origin from the click; the chrome-extension:// ALLOWED_ORIGINS interim note is removed
- **Defensive request**: https-only API (http only for localhost), credentials omit, redirect manual, no-store; status text is fixed strings plus a validated problem code, saved_at and Retry-After

## Deviations
- Plan: twitter.com fallback → Actual: x.com only, both cookies required (reason: X sessions live on .x.com; a twitter.com pair would be stale)

## Recommendations
- Operator: load 1.1.0 unpacked, grant the tailnet host, sync both sites against gx-10, then drop chrome-extension://<id> from ALLOWED_ORIGINS
- Alert text could also mention the extension's Sync X session button
