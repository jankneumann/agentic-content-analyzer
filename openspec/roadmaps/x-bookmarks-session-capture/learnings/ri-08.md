# Learning: ri-08

## Decisions
- **aca auth session substack|x**: src/cli/session_commands.py: Playwright launch_persistent_context on browser_profiles_dir()/<site> (0700), capture without login when the profile already holds cookies, else poll context.cookies() until --timeout; one httpx validation request, one sink.write(), apply_local_write with the sink's exact saved_at
- **Shared X web constants**: src/ingestion/x_web.py holds X_WEB_BEARER_TOKEN, user agent, X_ACCOUNT_SETTINGS_URL, cookie names and x_web_headers() for ri-11
- **Default sink**: bao when BAO_ADDR is set, else secrets-file; never Railway implicitly

## Deviations
- Plan: registration line in auth_commands.py → Actual: registered in src/cli/app.py (reason: avoid colliding with ri-06 edits)
- Plan: bearer token split to avoid scanner matches → Actual: host added a documented .gitleaks.toml allowlist entry; pinned gitleaks 8.21.2 finds no leaks in the files or branch history (reason: be explicit about a public client constant rather than rely on literal layout)

## Recommendations
- Playwright lives only in the release-smoke extra; add a browser-session extra so the capture command installs cleanly
- The sandbox Chromium build (1194) is older than Playwright 1.62 expects (1234); a real headed login on the workstation is still untested
- ri-11: import x_web_headers(); treat 401 on account/settings.json as session_expired
