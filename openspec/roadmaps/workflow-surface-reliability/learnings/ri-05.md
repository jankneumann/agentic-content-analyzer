# Learning: ri-05

## Decisions
- **Merged real-ingestion CI tiers only after resolving all reviewer findings**: PR #473 was mechanically mergeable but carried six unresolved Codex findings (4 P1, 2 P2); all were verified real and fixed (commit `bb4dc681`) before the rebase merge, not deferred.
- **Kept the durable-workflow tiers committing, not rolling back**: the harness submits through `OperationService` → durable queue → worker → persistence and commits rows, because the queue's asyncpg connection cannot see the ORM session's uncommitted writes.
- **Made the live tier's coverage derive from the policy**: parametrized the live network tier from `LIVE_ADAPTER_POLICIES` (14 live-eligible fixture-backed sources) instead of the six representative PR keys.

## Blockers
- **Masking fallback in the harness**: `claimed or claimed_from_run` replaced an explicit empty durable claim with the harness's private creation log, hiding the empty-durable-result regression → fall back to the run log only when there is no result record at all.
- **Misclassified DB write errors**: the classifier matched only `"persist"`/`"database write"`, so a real `IntegrityError` fell through to the adapter class → broadened to DB-write signatures grounded in the real `_ingestion_diagnostic` string, with a guard test.
- **Suppressed fixture coverage**: live-eligible sources skipped the fixture half → always run fixtures; live runs additionally.

## Recommendations
- For self-verifying test tiers, prove the assertion fails on the target regression — a green tier is not evidence the guard works.
- Ground failure-class matching in the real diagnostic string, not hand-picked keywords; lock it with a guard test.
- Exclude heavyweight committing suites from the default CI shards by marker (`not real_ingest`) so a real-credential drive never runs outside its dedicated job.
- Continue RI-06 (CLI gen-eval coverage) on top of merged main (depends on ri-03, ri-04).
