# Learning: ri-11

## Decisions
- **Deferred URL v2 on evidence**: `/api/v1` already provides the namespace; no named
  incompatible successor currently justifies a parallel implementation.
- **Kept version identities separate**: document, event, queue, and URL versions solve
  different compatibility problems.
- **Raised the future trigger bar**: iOS Shortcuts and `agentic-assistant` are real
  independently updated consumers, so old-client evidence is required before their
  contracts change.

## Recommendations
- Resolve GitHub issue #492 before the next affected breaking change.
- Do not assume optional response fields are compatible with strict generated clients.
- Create a narrow v2 adapter only for the first exact incompatible surface that needs
  an overlap window.
