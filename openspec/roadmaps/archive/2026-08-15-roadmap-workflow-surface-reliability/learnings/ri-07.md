# Learning: ri-07

## Decisions
- **Keep operations authoritative**: Reused pgqueuer_jobs typed results, checkpoints, retries, and parent-child identity instead of introducing a second ingestion-run state machine.
- **Bound public history**: Added operation-derived compact history with HMAC filter-bound cursors, opaque configured-source keys, bounded projections, and measured PostgreSQL indexes.
- **Serialize graph mutation**: Applied one root-scoped transaction advisory-lock invariant across child enqueue, retry, and graph retention.

## Blockers
- READ COMMITTED recursive scans allowed a depth-three child insertion race. → Child enqueue and cleanup now share a root graph transaction lock with lineage revalidation.
- Pipeline retry child-first updates could deadlock root-first retention locking. → Retry now takes the graph lock and root row lock before child and parent lifecycle updates.

## Deviations
- Plan: Two recursive row-lock passes were expected to stabilize retention membership. → Actual: A shared graph mutation lock became the durable concurrency invariant. (reason: Independent review demonstrated arbitrarily deep insert races and retry lock inversion.)

## Recommendations
- Resolve adapter log redaction follow-up in GitHub issue #481 before treating private configured-source locator logging as fully closed.
